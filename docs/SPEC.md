# 仕様一覧・ガチャ／進化ルール・バランス設定（コアループ実証版 v0.2）

数値はすべて [`js/config.js`](../js/config.js) にあり、ここを書き換えるだけで調整できます。
以下はこの版の初期値です。

## 1. コアループ

```
魔素でガチャ → 因子を入手 → 進化（因子を消費）→ スライムの自動行動が変わる
      ↑                                                   ↓
      └──────── 捕食で魔素を獲得 ←── 自律シミュレーション ─┘
```

- プレイヤーはスライムを直接操作しない。操作するのはガチャ・進化・血統（分岐／行動方針／共鳴強化）だけ。
- ステージ制・ウェーブ制はなし。1つのフィールドがずっと続き、獲物は繁殖と流入で回復する。
- 課金はなし（買い切り想定）。ガチャは魔素だけで引く。

## 2. 能力因子（10種）

| 因子 | レア | 主な用途 |
|---|---|---|
| 🔥 炎 | R | すべての基本形態に必要（最初に1個配布） |
| 🌀 転がる | R | 火達磨、火炎大行進 |
| 💧 水 | R | 蒸気（複属性核と組み合わせ） |
| ☠️ 毒 | R | 毒炎（複属性核と組み合わせ） |
| 🛡️ 硬化 | R | 溶岩巨龍、共鳴強化 |
| 👁️ 感知 | R | 共鳴強化 |
| 🧬 増殖 | SR | 炎の軍勢、火の玉乱舞、自爆感染体 |
| 💥 爆裂 | SR | 連鎖爆破 |
| 🦷 捕食 | SR | 灼熱龍 |
| 💠 複属性核 | SSR | 複合属性（蒸気・毒炎）。最初から抽選対象 |

## 3. ガチャ

| ガチャ | 単発 | 10連 | 特徴 |
|---|---|---|---|
| スタンダード招来 | 100 | 1000 | バランス型（R75% / SR22% / SSR3%）。**初回10連は無料** |
| 本能の祭壇 | 150 | 1500 | 行動因子（転がる22%、増殖・爆裂・捕食 各13%）が出やすい |
| 元素の泉 | 120 | 1200 | 炎24%・水20%・毒20%、複属性核6% |

因子ごとの排出率はゲーム内の「排出率を見る」に表示しています（`config.js` の値をそのまま表示）。

**抽選ルール**
- 表示された排出率どおりの、重み付きの完全ランダム抽選。進化目標や所持状況で結果を裏で操作することは一切しない。
- 保証は次の2つだけ（どちらも画面に表示）：
  - 10連の10枠目は、それまでの9枠にSR以上がなければSR以上が確定（SR以上の中で排出率どおりに抽選）。
  - SSRが出ないまま60回引くと、次の1回はSSR確定（天井。全ガチャ共通カウント）。
- 「必要!」タグ：引いた因子が、どれかの血統の次の進化に足りない因子なら表示。RやSRでも当たりとして強調する。
- その引きで新しい進化の因子が揃うと、結果画面に「🔓 ○○が解放！」と表示。魔素も足りていれば **[今すぐ進化]** ボタンが出て、1クリックで進化できる。

## 4. 進化

### 基本形態（炎＋行動因子、魔素不要）

| 形態 | 必要因子 | 移動 | 狙う獲物 | 狩り方 | 長所／短所 |
|---|---|---|---|---|---|
| 火達磨 | 炎＋転がる | 最高速280。小回りが利かず、弧を描いて走り回る | 跳ね虫（小型・素早い）を最優先 | 体当たり（速度に比例した衝突ダメージ）。炎の轍が残り、通った跡の小物を焼く | 速いが体が小さく、大物は狩れない |
| 炎の軍勢 | 炎＋増殖 | 中速。個体ごとにばらばらに獲物を探す | 丸虫・群れ蟲など、近くの中小型 | 接触して捕食。同じ獲物を取り合わないよう分担する | 栄養が貯まると分裂（最大16体）。維持費があり、獲物が減ると飢えて数が減る |
| 連鎖爆破 | 炎＋爆裂 | 低〜中速。**獲物の密集地**を探して突っ込む | 群れ蟲の巣 | 倒した獲物が爆発し、巻き込まれて死んだ獲物もまた爆発する（0.09秒ごとに連鎖） | 密集地では大量捕食。連鎖が長いほど魔素ボーナス（最大3倍）。巣を食べ尽くすと次の巣まで移動が必要 |
| 灼熱龍 | 炎＋捕食 | 鈍重（60）。巨大化する（半径20→36） | 角獣（大型）だけ。小物は無視 | 射程内で止まり、炎の吐息で焼いて丸呑み | 角獣の反撃を受ける。体力が35%を切ると休眠して回復。角獣がいないと何もしない |

### 追加進化（基本形態＋後から追加した因子、魔素400）

| 派生 | 元の形態＋因子 | 変化 |
|---|---|---|
| 火の玉乱舞 | 火達磨＋増殖 | 火の玉に分裂（最大7体）。フィールド中を炎の轍で埋める |
| 火炎大行進 | 炎の軍勢＋転がる | 群れ全体が隊列を組み（ボイド）、獲物の多い地帯へ波のように転がり進む。最大28体 |
| 自爆感染体 | 連鎖爆破＋増殖 | 自爆する子体を産み、離れた群れへ送り込んで連鎖爆発を起こす |
| 溶岩巨龍 | 灼熱龍＋硬化 | さらに巨大化（半径50）。被ダメ70%軽減、周囲を焼くオーラ、溶岩の足跡 |

同じ「増殖」でも、火達磨に足せば火の玉乱舞、連鎖爆破に足せば自爆感染体になる。最初に選んだ系統で、その後の派生が変わる。

### 複合属性（SSR 複属性核＋属性因子、魔素500、基本形態以上に上乗せ）

| 属性 | 必要 | 効果 |
|---|---|---|
| 蒸気 | 複属性核＋水 | 4秒ごとに蒸気を噴き、範囲内の獲物を70%減速させ、被ダメを+30%にする |
| 毒炎 | 複属性核＋毒 | 攻撃に毒を付与。毒で死んだ獲物は周囲3体に毒を感染させる |

### その他
- **転生**：血統を基本スライムに戻し、別の系統を試せる（使った因子は戻らない。Lvは維持）。
- **共鳴強化**：その血統の進化で使った因子（または硬化・感知）を1つ消費してLv+1（最大Lv5）。Lvごとに攻撃+15%、体力+10%、能力（爆発半径・分裂上限など）+8〜12%。コストは魔素50×現在のLv。重複した因子の使い道。

## 5. 血統管理
- 血統は最大3本。分岐コストは2本目300、3本目900魔素。
- 増殖で生まれた個体は親の血統を引き継ぐ（個別操作はなし）。血統分岐は増殖とは別機能で、新しい基本スライムから別の系統を育てる。
- 血統ごとに **行動方針** を設定できる。
  - 攻撃的：攻撃+12%、被ダメ+15%、逃げない、大物を狙いやすい
  - 標準：体力25%で角獣から逃げる
  - 慎重：攻撃-8%、被ダメ-15%、体力50%で逃げる。群れ型は栄養を貯めてから分裂する
- すべての血統が同じフィールドで獲物を取り合う。

## 6. 自律シミュレーション

| 獲物 | 特徴 | 魔素 | 回復 |
|---|---|---|---|
| 跳ね虫 | 小型・高速。スライムが近づくと跳ねて逃げる | 5 | 生息上限70までロジスティック繁殖＋外から流入 |
| 群れ蟲 | 極小。6か所の巣に30匹ずつ密集している | 1.4 | 巣ごとに再生（空になっても再生する） |
| 丸虫 | 中型・鈍足。逃げない | 7 | 生息上限26まで繁殖＋流入 |
| 角獣 | 大型（HP420）。攻撃されると突進して反撃（24ダメージ） | 90 | 4頭まで、14秒ごとに補充 |

- 食べ尽くされても、流入と巣の再生で必ず回復する（どの獲物も絶滅しない）。
- 捕食すると、魔素（共通の通貨）と栄養（その個体の成長・分裂用）が手に入る。

## 7. 画面・操作
- 画面の大半はフィールド。右に幅360pxのパネル（ガチャ／進化／血統）。
- フィールド：クリックでその血統を選択、ホイールでズーム、ドラッグで移動、ダブルクリックで全体表示。
- 📷 追従（Fキー）：選んだ血統をズームで追いかける。群れの場合は全員が画面に入るように自動でズームする。
- 🎯：各スライムから狙っている獲物まで点線を引く（何を狙っているかが見える）。
- 一時停止（Space）、1x/2x/4x。
- 進化できるようになるとトースト通知と進化タブの「!」で知らせ、1クリックで進化できる。
- ガチャの演出は約1秒。クリックかSpaceでスキップできる。
- 自動セーブ：5秒ごと、タブを閉じるとき、ガチャや進化の直後に localStorage へ保存。⚙メニューからセーブ初期化。

## 8. 形態比較ラボ（`lab.html`）
- 同じシードの世界を4つ並べ、それぞれに1形態だけを置いて同時に動かす。
- URL例：`lab.html?seed=42&forms=fireball,legion,chain,dragon`（`chain+steam` のように属性も指定できる）。
- 魔素/分、獲物ごとの捕食比率、移動量、個体数、最大連鎖をリアルタイムに表示する。
