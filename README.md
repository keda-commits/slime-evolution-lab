# スライム進化ラボ（Slime Evolution Lab）

ガチャで **能力因子** を引き、スライムの **進化** を選ぶ。あとはスライムが自分で探索・捕食・戦闘する。
自分が引いた因子でスライムがどう変わるかを観察する、ブラウザゲームの試作（コアループ実証版）です。

## ▶ プレイ
**https://keda-commits.github.io/slime-evolution-lab/**

インストールもログインも不要です。PC版の Chrome / Edge で動作を確認しています。進行状況はブラウザ（localStorage）に自動で保存されます。

## 遊び方
1. **はじめる** → 右パネルの **初回無料10連!** を押す
2. 結果画面の **今すぐ進化** を押す（または「進化」タブから）
3. スライムが自動で狩りを始める。捕食すると **魔素** が貯まる
4. 「進化」タブで次の進化に足りない因子を確認し、その因子が出やすいガチャを引く
5. 「血統」タブで血統を分岐させると、別の進化系統を同時に育てられる

| 操作 | 内容 |
|---|---|
| クリック（フィールド） | そのスライムの血統を選択 |
| ホイール／ドラッグ／ダブルクリック | ズーム／視点移動／全体表示 |
| 📷 追従（F） | 選択中の血統を自動で追いかける |
| 🎯 | 各スライムが狙っている獲物を点線で表示 |
| Space | 一時停止（ガチャ演出中はスキップ） |
| 1x / 2x / 4x | ゲーム速度 |
| ⚙ → セーブ初期化 | 最初からやり直す |
| ⚙ → 形態比較ラボ | 4つの形態を同じ条件で並べて比較する（[lab.html](https://keda-commits.github.io/slime-evolution-lab/lab.html)） |

## 主な進化
| 形態 | 必要因子 | 行動 |
|---|---|---|
| 火達磨 | 炎＋転がる | 高速で走り回り、小型で素早い跳ね虫を轢いて狩る。炎の轍が残る |
| 炎の軍勢 | 炎＋増殖 | 分裂して群れになり、それぞれが獲物を探す。維持費があり、飢えると減る |
| 連鎖爆破 | 炎＋爆裂 | 倒した獲物が爆発して連鎖する。群れの巣に突っ込む |
| 灼熱龍 | 炎＋捕食 | 巨大化して大型の角獣だけを狙い、炎の吐息で焼いて丸呑みにする |

追加進化（火の玉乱舞／火炎大行進／自爆感染体／溶岩巨龍）と、SSR「複属性核」による複合属性（蒸気／毒炎）もあります。詳しくは [docs/SPEC.md](docs/SPEC.md) を参照してください。

## 開発

ビルドは不要です（素のHTML・CSS・JavaScriptのESモジュール）。

```bash
# ローカルで起動 → http://localhost:8765/
python -m http.server 8765

# 自動テスト（形態比較＋15分自動プレイ）
npm test

# テスト結果を docs/ に書き出す
npm run report
```

- バランス調整：[`js/config.js`](js/config.js) に、ガチャの排出率、コスト、進化レシピ、獲物とスライムの数値がまとまっています。
- 構成：`js/sim.js`（自律シミュレーション。DOMに依存せず、Nodeからも動く）／`js/game.js`（ガチャ・進化・血統・セーブ）／`js/render.js`（描画と演出）／`js/main.js`（UI）／`js/lab.js`（比較ラボ）

### 公開の仕組み
`main` ブランチに push すると、GitHub Actions（`.github/workflows/pages.yml`）が次の順で実行されます。
1. シミュレーションテストを実行する（失敗したら公開しない）
2. `index.html`・`lab.html`・`css/`・`js/` を GitHub Pages へデプロイする

ファイルはすべて相対パスで読み込むので、`/slime-evolution-lab/` のサブパスでもそのまま動きます。
