- 基本4形態の魔素効率は390〜666/分で、差は1.7倍以内。どれも選ぶ価値がある

**画面上の違い**（ブラウザと形態比較ラボで確認）

- 炎の軍勢：小さな炎の冠を付けた個体が分裂して散らばり、それぞれが獲物へ点線を伸ばす。飢えると「腹ペコ」と表示される。
- 連鎖爆破：導火線付きの赤い体で巣へ突っ込み、爆発リングと連鎖ラインが広がって「CHAIN ×31!」と出る。
- 灼熱龍：角とトゲのある巨体が角獣と向き合い、扇形の炎の吐息で焼き、獲物が吸い込まれるように丸呑みされる。HPが減ると「Zz」と休眠する。

## 2. 15分の自動プレイ（8シード×2つのボット戦略）

詳細は [`sim-autoplay.md`](sim-autoplay.md) にあります。
- ボット `random`：進化先を毎回ランダムに選ぶ
- ボット `goal`：まだ見ていない形態を優先し、育ちきった血統は転生させる
- どちらも、欲しい因子が最も出やすいガチャを選び、進化に必要な魔素があるときはガチャを我慢して貯める

| 指標 | 結果 |
|---|---|
| 初めての進化 | 全16回とも開始から4秒（無料10連の直後） |
| 2回目の進化（追加進化） | 全16回で到達。57〜198秒（中央値 約100秒） |
| 複合属性（SSR）まで到達 | 16/16。122〜654秒 |
| 15分間のガチャ回数 | 31〜100回（平均64回） |
| 体験した形態の数 | random 3〜7、goal 7〜9（全9形態） |
| 魔素の獲得量 | 1分目 約300 → 3血統になった後は 約1000〜1300/分 |

**判定（4/4 PASS）**：60秒以内に初進化／全シードで追加進化に到達／5分以内に2回目の進化／平均3形態以上を体験

**進行が詰まらないか**：無料10連は10枠目でSR（増殖・爆裂・捕食のどれか）が確定し、炎は最初に1個配っているので、**どんな引きでも必ず1つは基本形態に進化できます**。15分の間に進行不能になったシードはありませんでした。

**開発中に見つけて直した詰まり**
- 最初のボットは、進化に必要な魔素400が貯まる前に、毎回単発ガチャで使い切っていました。結果、15分ずっと「SSR待ち」になっていました。人間のプレイヤーでも起こり得るので、UIで「因子は揃っています。あと魔素 ✦○○」と表示し、ガチャ結果でも足りない魔素の量を出すようにしました。

## 3. ゲームデザイン上の問題点（正直な評価）

1. **派生形態が「群れ蟲を食べる形態」に寄っていく**。火の玉乱舞（群れ蟲84%）、火炎大行進（87%）、自爆感染体（89%）、溶岩巨龍（75%）のように、追加進化はどれも群れ蟲が主食です。群れ蟲が一番多く、密集しているためです。動きや見た目ははっきり違いますが、「どの獲物を狙うか」の個性は基本形態より薄れています。特に溶岩巨龍は、オーラで周りの小物を焼くため、「大物狙い」の個性が弱まっています。
2. **コンテンツが6〜10分で尽きる**。randomボットでは、3血統すべてが最終形態＋属性になった後に、5〜7分間なにもしない時間がありました（最長無操作 349〜452秒）。最初の10〜15分で評価するには足りますが、その後に引き続ける動機（共鳴強化だけ）は弱いです。
3. **蒸気の価値が形態によって極端に違う**。連鎖爆破＋蒸気は、魔素効率が+5%しか上がりません。減速は火達磨には効きますが、もともと鈍足の群れ蟲には意味が薄いです。SSRを引いたのに嬉しくない組み合わせがあります。
4. **灼熱龍は角獣の数に依存する**。角獣は4頭までなので、3血統がすべて龍系になると取り合いになって、休眠ばかりになる可能性があります（血統どうしの取り合いは数値ではまだ検証していません）。
5. **ガチャの「欲しい」が複属性核（SSR 2〜6%）に集中しやすい**。追加進化まで終わると、残りの目標がSSRだけになり、外れが続く時間が長くなります。天井60回はありますが、そこまでは単調です。
6. **炎の軍勢は序盤が地味**。3体から始まり、分裂して数が増えるまで30秒ほどかかります。進化した直後の「劇的な変化」は、他の3形態より弱いです。

## 5. 次の試作に向けた改善提案
1. **獲物の生態を形態ごとに分ける**：派生形態ごとに専用の獲物を足す。例：火の玉乱舞は跳ね虫の群れ、溶岩巨龍は硬い殻を持つ大型。あるいは、群れ蟲の魔素を下げて丸虫や角獣を上げ、派生の主食が分かれるようにする。
2. **第3段階の進化とクロス派生**：火の玉乱舞＋爆裂、灼熱龍＋増殖（子龍）など、系統をまたぐ組み合わせを少しだけ足す。「この因子をどの系統に使うか」で迷う場面を作る。
3. **属性の効果を形態ごとに変える**：同じ蒸気でも、連鎖爆破なら蒸気爆発（爆発半径を拡大）、灼熱龍なら吐息の射程延長、のようにする。SSRは常に当たりにする。
4. **血統どうしの相互作用**：獲物の取り合いだけでなく、「連鎖爆破の爆発が炎の軍勢の死骸を燃料にする」のような共生関係を作る。3血統の組み合わせ自体を楽しめるようにする。
5. **中盤以降の目標**：フィールドに数分に1度「ヌシ」（超大型の獲物）を出す。どの形態が倒せるかで差が出る、短い目標にする。
6. **炎の軍勢の初速**：進化した直後に5体へ分裂させ、最初の10秒は維持費を0にして、変化をはっきり見せる。
7. **人間のプレイテスト**：自動テストで測れるのは「詰まらない」「違いが出る」までです。「次を引きたくなるか」は、3〜5人に15分遊んでもらい、何回自発的にガチャを引いたか、どの時点で止めたかを記録して確かめるのがよいと思います。
